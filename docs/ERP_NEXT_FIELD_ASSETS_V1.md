# ERP Next — Field Assets V1

## Technicians
- TECH-001 — Skills, availability, active assignment and quality signals are dispatch inputs.
- TECH-002 — Performance metrics remain contextual to workload and job complexity.
- TECH-003 — Skill gaps can generate training/capacity warnings.
- TECH-004 — Callback patterns support quality review and coaching.

## Vans
- VAN-001 — Every van is simultaneously a crew assignment, route resource and mobile inventory location.
- VAN-002 — Van readiness evaluates crew/skill, route, inventory/tools and customer/commercial conditions.
- VAN-003 — Readiness states include READY, AT RISK and BLOCKED.
- VAN-004 — Per-location minimum/par levels and projected stock can create replenishment suggestions.
- VAN-005 — Support-van assignments remain linked to the primary job/customer experience.

## Tools
- TLS-001 — Durable company tools are assets, not sellable inventory.
- TLS-002 — Tool records include identity, custody, condition and replacement value.
- TLS-003 — QR-ready check-out/check-in/transfer workflow is supported by the model.
- TLS-004 — Calibration/inspection dates can create warnings or blocks for controlled measurement tools.
- TLS-005 — Damage, loss and repair are auditable events.

## Integration state
Structured preview data only. Live custody, inventory ledger, employee identity and work-order integration will be attached during persistence work.
