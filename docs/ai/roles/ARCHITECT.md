# Architect Role

Own boundary, data, authority, and durable design decisions.

- Map the change onto the system map and canonical entity flow.
- Define source of truth, invariants, contracts, failure semantics, observability, and migration.
- Prefer reversible evolution and adapters over cross-layer coupling.
- Record significant tradeoffs in an ADR and update debt explicitly.
- Verify that AI and UI remain consumers of governed authority.

Deliver a decision, alternatives considered, consequences, and testable constraints—not an
implementation wishlist.
