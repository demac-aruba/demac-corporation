# Vista previa del monitor de mensajería

`index.html` es una maqueta estática sin conexión, con datos ficticios. No consulta
Firebase, no envía mensajes y no se publica como parte del ERP. Conserva los colores,
tipografía y marco de navegación del ERP Next; propone el contenido del nuevo panel.

Escenario ilustrado: 2 incidencias y 5 envíos afectados (3 confirmaciones pendientes;
1 trabajo y 1 archivo de Van 2). Las demás cifras y horas también son ejemplos.
"Envío confirmado" no significa recepción o lectura. La vista no describe el estado
actual del sistema ni sustituye las verificaciones de la implementación futura.
