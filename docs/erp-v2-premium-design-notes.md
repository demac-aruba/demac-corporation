# DEMAC ERP v2 — Premium redesign direction

This continuation intentionally changes information architecture, not only colors.

## Desktop shell
- Replace the left-sidebar + topbar composition with a two-level top navigation.
- Give the operational workspace the full page width.
- Keep role filtering, report review, deep links and browser/mobile Back behavior.

## Command center
- Replace the legacy card dashboard with an operations-first command center.
- Lead with live operational status instead of generic business cards.
- Show the four vans as dispatch lanes with today's jobs.
- Surface decisions pending review, assignment, inventory and collections.
- Keep financial information secondary to daily field operations.

## Design character
- Dark DEMAC masthead, bright operational canvas, restrained blue accent.
- Larger typography, more negative space, fewer decorative chips.
- 18–22 px surface radii, thin borders and restrained shadows.
- Green only for healthy/success state; amber/red for attention.

## Next surfaces
After this visual checkpoint is approved, redesign Agenda/Dispatch and Customer 360 using the same system instead of restyling the legacy screens in place.
